# 第5章 实验设计与结果分析

本章围绕第4章提出的“基于语义增强执行路径证据的漏洞行级定位与可解释方法”展开实验验证。实验目标是在已有 MSAVD/DeepWuKong 漏洞检测模型的基础上，评估不同定位分数策略对漏洞行级定位效果的影响，并分析语义风险增强对模型解释结果的改进作用。

需要说明的是，本文实验不重新训练漏洞检测模型，而是加载已经训练完成的 checkpoint，在测试集上执行解释与定位流程。这样可以保证实验重点集中在漏洞行级定位方法本身，避免模型重新训练带来的额外变量影响。

## 5.1 实验目的

本文实验主要回答以下问题：

（1）仅使用模型内部注意力或节点证据分数时，漏洞行级定位效果如何；

（2）仅使用代码语义风险规则进行排序时，是否能够捕获真实漏洞行；

（3）将注意力证据与语义风险分数融合后，是否能够进一步提升 Top-k 命中率、MRR 和 IFA 等定位指标；

（4）轻量反事实扰动能否作为候选漏洞行可信度验证手段，辅助分析候选行对模型预测概率的影响。

通过上述实验，本文希望证明：在漏洞行级定位任务中，仅依赖神经模型内部证据并不充分；将危险代码语义先验引入定位排序后，可以显著改善候选漏洞行的排序质量。

## 5.2 实验数据集与标签构造

本文实验采用 SARD 测试集作为主要评估数据。测试样本以 XFG 文件形式存储，每个 XFG 样本包含图结构、节点 token、源代码行号以及样本级漏洞标签。由于漏洞行级定位需要真实漏洞行作为评价依据，本文采用 XFG 文件名中的行号信息作为行级 ground truth。

例如，对于如下 XFG 文件路径：

```text
.../XFG/87595/call/116.xfg.pkl
```

其文件名为 `116.xfg.pkl`，取第一个点号之前的数字 `116` 作为真实漏洞行号，即：

```text
true_vul_lines = [116]
```

该策略仅对漏洞样本生效。对于非漏洞样本，真实漏洞行集合设为空，避免从注释关键词或弱规则中为正常样本错误抽取漏洞行标签。标签统计结果如下：

```text
dataset: SARD test
total_samples: 2648
positive_samples: 589
negative_samples: 2059
positive_with_line_labels: 589
negative_with_line_labels_should_be_zero: 0
avg_vul_lines_per_positive_sample: 1.0
```

由上述统计可知，测试集中共有 2648 个样本，其中漏洞样本 589 个，非漏洞样本 2059 个。所有漏洞样本均成功抽取到行级标签，且非漏洞样本未被错误分配漏洞行标签，说明本文采用的 XFG 文件名行号标签策略满足本实验的评价需求。

## 5.3 实验设置

实验在已有 MSAVD/DeepWuKong 模型基础上进行。模型 checkpoint 加载后，首先输出每个样本的漏洞预测概率；随后，解释模块为每个样本中的源代码行计算定位分数，并输出 Top-k 候选漏洞行。本文不修改原模型结构、不重新训练模型，也不改变原始数据预处理流程。

实验主要比较以下三类排序策略：

（1）Attention-only。该方法仅使用模型内部节点或行级证据分数进行排序，是本文的基础对照方法。该方法反映已有模型在不引入额外安全语义规则时的行级定位能力。

（2）Semantic-only。该方法仅根据源代码文本中的危险 API、内存操作、输入函数、数组与指针访问、长度边界函数和算术操作等规则计算语义风险分数，并据此排序。该方法用于评估安全语义规则本身对漏洞行定位的有效性。

（3）Attention + Semantic。该方法融合归一化后的注意力证据分数与语义风险分数，融合公式为：

\[
FinalScore(l)=(1-\lambda)AttentionScore_{norm}(l)+\lambda SemanticScore_{norm}(l)
\]

其中，\(\lambda\) 为语义风险权重。根据权重扫描结果，本文最终采用 \(\lambda=0.9\) 作为最佳配置。

此外，本文实现轻量 Counterfactual Score 模块。该模块仅对当前 Top-k 候选行执行 token-level length-preserving mask，并根据漏洞概率下降计算候选行可信度：

\[
cf\_score(l)=\max(0,P_{original}-P_{masked})
\]

反事实模块主要用于解释可信度验证，不作为本文最终主排序方法。

## 5.4 评价指标

本文仅在成功抽取到真实漏洞行标签的漏洞样本上计算定位指标。采用的评价指标包括 Top-1 Accuracy、Top-3 Accuracy、Top-5 Accuracy、MRR 和 IFA。

Top-k Accuracy 表示排序前 k 个候选行中是否命中任意真实漏洞行，其定义为：

\[
Top\text{-}k=\frac{1}{N}\sum_{i=1}^{N}I(R_i^k\cap Y_i\neq\varnothing)
\]

其中，\(N\) 表示参与评价的漏洞样本数量，\(R_i^k\) 表示第 \(i\) 个样本排名前 k 的候选行集合，\(Y_i\) 表示真实漏洞行集合。

MRR（Mean Reciprocal Rank）用于衡量第一个真实漏洞行在排序结果中的平均倒数排名：

\[
MRR=\frac{1}{N}\sum_{i=1}^{N}\frac{1}{rank_i}
\]

其中，\(rank_i\) 表示第 \(i\) 个样本中第一个真实漏洞行的排名。

IFA（Initial False Alarms）表示找到第一个真实漏洞行之前排在前面的错误候选行数量。IFA 越低，说明安全分析人员在定位真实漏洞行之前需要检查的无关代码行越少。

## 5.5 实验结果

### 5.5.1 Attention-only 基线结果

首先，本文评估仅使用模型内部注意力或节点证据分数的定位效果。实验结果如下：

```text
method: Attention-only / Minimal
evaluated_samples: 589
top1_acc: 0.2920
top3_acc: 0.5772
top5_acc: 0.7759
mrr: 0.4867
ifa: 3.3141
```

可以看出，Attention-only 方法在 Top-5 指标上能够达到 0.7759，说明模型内部证据已经具有一定漏洞定位能力。然而，其 Top-1 Accuracy 仅为 0.2920，IFA 为 3.3141，表明真实漏洞行往往不能被排在首位，安全分析人员仍需检查多个候选行才能定位真实漏洞位置。

造成这一现象的原因可能在于，神经模型注意力不一定直接聚焦于危险操作语句本身，而可能关注变量定义、条件判断、数据传递路径或其他上下文节点。这些上下文语句虽然对模型判断有帮助，但并不一定是实际漏洞行。因此，仅依赖模型内部证据难以充分满足漏洞行级定位需求。

### 5.5.2 Attention + Semantic 最佳结果

在引入语义风险分数后，本文对不同语义权重进行了扫描。当前最佳配置为：

```text
score_mode = attention_semantic
semantic_weight = 0.9
```

其完整结果如下：

```text
evaluated_samples = 589
top1_acc = 0.4041
top3_acc = 0.8353
top5_acc = 0.9474
mrr = 0.6272
ifa = 1.3447
```

与 Attention-only 基线相比，Attention + Semantic 方法取得了明显提升。Top-1 Accuracy 从 0.2920 提升到 0.4041，说明更多真实漏洞行被排在第一位；Top-3 Accuracy 从 0.5772 提升到 0.8353，Top-5 Accuracy 从 0.7759 提升到 0.9474，表明语义增强后真实漏洞行更稳定地出现在靠前候选集合中。同时，MRR 从 0.4867 提升到 0.6272，IFA 从 3.3141 降低到 1.3447，说明安全分析人员在找到真实漏洞行之前需要检查的错误候选行显著减少。

该结果说明，危险 API、内存操作、输入源、数组指针访问和长度边界函数等安全语义特征对漏洞行级定位具有重要作用。注意力证据能够提供模型的执行路径关注信息，而语义风险分数能够将排序结果进一步拉向具有明确漏洞语义的代码行。二者融合后，能够更好地兼顾模型判别依据和漏洞审计经验。

### 5.5.3 反事实可信度验证

本文进一步实现了轻量反事实扰动模块，用于验证 Top-k 候选行对模型漏洞预测概率的影响。该模块对候选行对应节点进行 token-level length-preserving mask，并计算 mask 前后的漏洞概率下降值。

需要注意的是，反事实模块主要用于解释可信度验证，而不是当前实验中的最终主排序模块。因此，在论文结果表中可将其作为辅助分析结果展示，例如统计候选行平均概率下降、真实漏洞行的平均概率下降，以及概率下降较大的候选行是否更可能是真实漏洞行。

截至本文当前实验整理阶段，已完成 Attention-only、Semantic-only 和 Attention + Semantic 权重扫描，最佳主排序结果已经确定为 `semantic_weight=0.9` 的 Attention + Semantic 方法。Counterfactual Score 的完整统计结果需要在服务器完成 `--limit 20`、`--limit 100` 和 full 运行后再填入，本文不在此处编造尚未运行的指标。

## 5.6 结果分析

从实验结果可以看出，语义风险增强显著提升了漏洞行级定位性能。其主要原因包括以下几点。

第一，漏洞行通常包含明确的危险操作语义。例如，缓冲区溢出漏洞常与字符串拷贝、内存拷贝和长度计算有关；输入校验不足漏洞常与外部输入读取函数相关；内存安全漏洞常与指针访问、数组访问和内存管理函数相关。语义风险分数能够直接捕获这些模式，因此有助于将真实漏洞行提升到更靠前位置。

第二，模型注意力更擅长刻画执行路径上下文，而语义规则更擅长识别危险语句本身。二者并非替代关系，而是互补关系。Attention-only 方法可能将变量传播路径或条件判断语句排在前列，而 Semantic Score 能够强化真正包含危险 API 或危险内存访问的代码行。融合后，排序结果更接近人工漏洞审计中的关注重点。

第三，较高的语义权重 \(\lambda=0.9\) 表明，在当前 SARD/XFG 行级定位任务中，显式安全语义对于定位真实漏洞行具有较强贡献。不过，保留少量注意力证据仍然是必要的，因为注意力分数能够提供模型对执行路径上下文的判断，避免纯规则方法在多个危险语句同时出现时缺乏区分能力。

第四，IFA 指标的大幅降低具有实际意义。漏洞定位工具不仅需要提高命中率，还需要减少安全分析人员在真实漏洞行之前查看的无关候选行数量。Attention + Semantic 方法将 IFA 从 3.3141 降低到 1.3447，说明该方法能够明显减少人工审计成本。

## 5.7 本章小结

本章对基于语义增强执行路径证据的漏洞行级定位与可解释方法进行了实验验证。实验基于 SARD 测试集，共包含 2648 个测试样本，其中 589 个漏洞样本成功抽取到行级标签。实验结果表明，Attention-only 基线已经具备一定定位能力，但在 Top-1 Accuracy 和 IFA 指标上仍存在不足。引入语义风险分数并与注意力证据融合后，最佳配置 `semantic_weight=0.9` 在 589 个漏洞样本上取得了 Top-1 Accuracy 0.4041、Top-3 Accuracy 0.8353、Top-5 Accuracy 0.9474、MRR 0.6272 和 IFA 1.3447 的结果，显著优于 Attention-only 基线。

上述结果表明，安全语义规则能够有效增强模型内部执行路径证据，提高漏洞行级定位结果的准确性和可解释性。反事实扰动模块作为可信度验证手段，可进一步辅助分析候选漏洞行对模型预测概率的实际影响，其完整统计结果将在服务器完成对应实验后补充。
