# 第5章 实验设计与结果分析

本章围绕第4章提出的“基于语义增强执行路径证据的漏洞行级定位与可解释方法”进行实验验证。实验基于已有 MSAVD/DeepWuKong 漏洞检测模型展开，不重新训练模型，不改变原始数据预处理流程，而是在测试阶段对模型输出结果进行行级定位解释。实验重点在于比较不同定位分数策略对漏洞行排序效果的影响，并分析语义风险增强与反事实扰动验证模块在漏洞行级定位任务中的作用。

## 5.1 实验环境与数据集

本文实验在已训练完成的 MSAVD/DeepWuKong 模型基础上进行。实验流程首先加载训练好的模型 checkpoint，对测试集样本输出漏洞预测概率；随后，解释模块根据模型证据分数、语义风险分数以及反事实扰动分数生成候选漏洞行排序结果。整个实验过程不修改模型结构，不重新训练参数，也不改变原始 XFG 构造方式，从而保证不同方法之间的比较集中于定位解释策略本身。

实验数据采用 SARD 测试集。测试样本以 XFG 文件形式组织，每个 XFG 样本包含图结构、节点 token、源代码行号和样本级漏洞标签。由于本文研究目标是漏洞行级定位，因此需要为漏洞样本构造真实漏洞行标签。本文采用 `xfg_stem` 策略，即从 XFG 文件名中提取真实漏洞行号。例如：

```text
116.xfg.pkl -> true_vul_lines = [116]
```

该策略仅对正样本生成漏洞行标签；对于负样本，不生成漏洞行标签，从而避免将正常样本中的注释关键词或危险 API 误识别为真实漏洞行。测试集标签统计如下：

| 项目 | 数量 |
| --- | ---: |
| 总样本数 | 2648 |
| 正样本数 | 589 |
| 负样本数 | 2059 |
| 具有行级标签的正样本数 | 589 |
| 被分配漏洞行标签的负样本数 | 0 |

由表可知，SARD 测试集中共有 2648 个样本，其中正样本 589 个，负样本 2059 个。所有正样本均成功获得行级漏洞标签，负样本未生成漏洞行标签。因此，本文后续定位指标仅在 589 个具有行级标签的正样本上计算。

## 5.2 评价指标

本文采用 Top-1 Accuracy、Top-3 Accuracy、Top-5 Accuracy、MRR 和 IFA 五个指标评估漏洞行级定位效果。

Top-k Accuracy 表示预测排序前 k 个候选代码行中是否命中任意真实漏洞行。对于第 \(i\) 个样本，设模型输出的前 k 个候选行集合为 \(R_i^k\)，真实漏洞行集合为 \(Y_i\)，则 Top-k Accuracy 定义为：

\[
Top\text{-}k=\frac{1}{N}\sum_{i=1}^{N}I(R_i^k\cap Y_i\neq\varnothing)
\]

其中，\(N\) 表示参与评价的漏洞样本数量，本文中 \(N=589\)。Top-k Accuracy 越高，说明真实漏洞行越容易出现在靠前候选集合中。

MRR（Mean Reciprocal Rank）用于衡量第一个真实漏洞行在排序列表中的平均倒数排名：

\[
MRR=\frac{1}{N}\sum_{i=1}^{N}\frac{1}{rank_i}
\]

其中，\(rank_i\) 表示第 \(i\) 个样本中第一个真实漏洞行的排名。MRR 越高，说明真实漏洞行整体排名越靠前。

IFA（Initial False Alarms）表示找到第一个真实漏洞行之前需要检查的非漏洞候选行数量。若真实漏洞行排名为第 \(r\) 位，则该样本的 IFA 为 \(r-1\)。IFA 越低，说明安全分析人员在发现真实漏洞行之前需要查看的无关代码行越少，人工审计成本越低。因此，与 Top-k Accuracy 和 MRR 不同，IFA 是越低越好的指标。

## 5.3 实验设置

本文比较以下五类定位策略。

（1）Attention-only。该方法仅使用模型内部节点或行级证据分数进行排序，作为基础对照方法。其结果反映已有漏洞检测模型在不引入额外语义规则时的行级定位能力。

（2）Semantic-only。该方法不使用模型注意力分数，仅根据代码行文本中的安全语义规则计算风险分数。语义规则包括危险 API、内存管理 API、输入源函数、数组或指针访问、长度边界相关函数以及算术操作等。

（3）Counterfactual-only。该方法仅使用轻量反事实扰动得到的概率下降值进行排序。对于候选行，采用 token-level length-preserving mask 进行扰动，并计算：

\[
cf\_score(l)=\max(0,P_{original}-P_{masked})
\]

其中，\(P_{original}\) 表示原始样本漏洞预测概率，\(P_{masked}\) 表示对候选行 mask 后的漏洞预测概率。

（4）Attention + Semantic。该方法融合注意力证据分数和语义风险分数。对于代码行 \(l\)，最终分数定义为：

\[
FinalScore(l)=(1-\lambda)AttentionScore_{norm}(l)+\lambda SemanticScore_{norm}(l)
\]

其中，\(\lambda\) 为语义权重。根据参数扫描结果，本文最终主方法采用 \(\lambda=0.9\)。

（5）Attention + Semantic + Counterfactual。该方法在注意力证据和语义风险的基础上进一步引入反事实分数。需要说明的是，本文不将该方法作为最终主方法，而是将其用于分析反事实扰动对候选漏洞行可信度和 Top-5 召回的影响。

## 5.4 消融实验结果与分析

表 5-1 给出了不同定位策略在 SARD 测试集 589 个漏洞样本上的结果。

**表 5-1 不同定位策略的消融实验结果**

| 方法 | Top-1 Acc | Top-3 Acc | Top-5 Acc | MRR | IFA |
| --- | ---: | ---: | ---: | ---: | ---: |
| Attention-only | 0.2920 | 0.5772 | 0.7759 | 0.4867 | 3.3141 |
| Semantic-only | 0.3531 | 0.7912 | 0.9168 | 0.5791 | 1.6486 |
| Counterfactual-only | 0.2767 | 0.6180 | 0.8014 | 0.4936 | 3.0153 |
| A+S, \(\lambda=0.9\) | 0.4041 | 0.8353 | 0.9474 | 0.6272 | 1.3447 |
| A+S+CF, Top5-best | 0.3922 | 0.8251 | 0.9542 | 0.6211 | 1.3463 |

从表中可以看出，Attention-only 方法具有一定定位能力，Top-5 Accuracy 达到 0.7759，但 Top-1 Accuracy 仅为 0.2920，IFA 为 3.3141。这说明模型内部证据能够覆盖部分真实漏洞行，但真实漏洞行往往未被排在最靠前位置。原因可能是模型注意力同时关注变量定义、条件判断、数据流传播等上下文节点，而这些节点虽然有助于漏洞检测，却不一定是实际漏洞语句。

Semantic-only 方法相比 Attention-only 有明显提升。其 Top-1 Accuracy 达到 0.3531，Top-3 Accuracy 达到 0.7912，Top-5 Accuracy 达到 0.9168，IFA 降低至 1.6486。这表明危险 API、输入函数、内存操作、数组指针访问和边界相关函数等语义规则与真实漏洞行具有较强相关性。在 SARD/XFG 的行级标签设置下，显式安全语义对于漏洞行定位具有重要作用。

Counterfactual-only 方法的 Top-1 Accuracy 为 0.2767，低于 Attention-only 和 Semantic-only，但其 Top-3 Accuracy 和 Top-5 Accuracy 分别达到 0.6180 和 0.8014，高于 Attention-only。这说明单独依赖概率下降值并不能稳定地将真实漏洞行排在第一位，但反事实扰动能够为一部分候选行提供有效的可信度信号。由于反事实分数受到 mask 策略、模型鲁棒性和候选行范围限制的影响，本文不将 Counterfactual-only 作为主排序方法。

A+S, \(\lambda=0.9\) 方法取得了整体最优的主排序性能。与 Attention-only 相比，其 Top-1 Accuracy 从 0.2920 提升到 0.4041，Top-3 Accuracy 从 0.5772 提升到 0.8353，Top-5 Accuracy 从 0.7759 提升到 0.9474，MRR 从 0.4867 提升到 0.6272，IFA 从 3.3141 降低到 1.3447。该结果说明，注意力证据与语义风险分数具有互补性：注意力分数反映模型对执行路径上下文的关注，语义分数则突出具有明确漏洞风险的代码行。二者融合后能够显著改善真实漏洞行的排序位置。

A+S+CF 在 Top-5 Accuracy 上达到 0.9542，高于 A+S 的 0.9474，说明反事实分数能够进一步增强 Top-5 候选集合的召回能力。然而，A+S+CF 的 Top-1 Accuracy、Top-3 Accuracy 和 MRR 均略低于 A+S, \(\lambda=0.9\)，IFA 也略高。因此，本文将 A+S, \(\lambda=0.9\) 确定为最终主方法，而将 CF 模块定位为可信度验证和 Top-5 召回增强模块。

## 5.5 参数敏感性分析

本文重点分析 Attention + Semantic 融合方法中语义权重 \(\lambda\) 的影响。融合公式如下：

\[
FinalScore(l)=(1-\lambda)AttentionScore_{norm}(l)+\lambda SemanticScore_{norm}(l)
\]

当 \(\lambda=0\) 时，方法退化为 Attention-only；当 \(\lambda=1\) 时，方法接近 Semantic-only。实验扫描结果表明，较高的语义权重能够显著提升漏洞行定位效果，最终最佳配置为 \(\lambda=0.9\)。该配置对应结果为 Top-1 Accuracy 0.4041、Top-3 Accuracy 0.8353、Top-5 Accuracy 0.9474、MRR 0.6272、IFA 1.3447。

从结果趋势可以看出，语义风险分数在当前任务中发挥了主导作用。这与 SARD/XFG 数据的漏洞行标注特点有关：真实漏洞行通常包含危险函数调用、内存访问、输入处理或长度计算等显式风险语义，因此提高语义权重有助于将真实漏洞行推向排序前列。但完全依赖语义规则也存在局限，Semantic-only 的 Top-1 Accuracy 为 0.3531，低于 A+S 的 0.4041。这说明模型注意力证据仍然能够补充上下文信息，在多个风险语句同时出现时为排序提供区分能力。

因此，\(\lambda=0.9\) 体现了一种较优平衡：最终排序主要依靠显式安全语义，同时保留少量模型执行路径证据。本文后续将 A+S, \(\lambda=0.9\) 作为主方法进行讨论。

## 5.6 反事实扰动分析

反事实扰动模块用于验证候选漏洞行对模型预测概率的影响。其基本思想是：如果某一候选行对漏洞预测具有关键作用，那么对该行对应节点进行 mask 后，模型输出的漏洞概率应当下降。本文采用轻量 token-level length-preserving mask，即仅替换候选行对应节点中的非 PAD token，并保持 PAD 位置不变，以避免 RNN 编码器出现长度为 0 的输入。

从实验结果看，Counterfactual-only 方法的 Top-1 Accuracy 为 0.2767，Top-3 Accuracy 为 0.6180，Top-5 Accuracy 为 0.8014，MRR 为 0.4936，IFA 为 3.0153。该结果说明，单独使用反事实概率下降值并不能获得最优的首位定位能力。这可能是因为轻量 mask 会受到 token 替换方式、模型对局部扰动的鲁棒性以及候选行选择范围的影响。

然而，反事实分数在 Top-5 召回方面具有一定价值。A+S+CF Top5-best 的 Top-5 Accuracy 达到 0.9542，高于 A+S, \(\lambda=0.9\) 的 0.9474。这说明 CF 模块能够帮助部分真实漏洞行进入前 5 个候选位置，对提高候选集合覆盖率有积极作用。与此同时，A+S+CF 的 Top-1 Accuracy 为 0.3922，低于 A+S 的 0.4041；MRR 为 0.6211，低于 A+S 的 0.6272。因此，若将 CF 直接作为主排序融合项，可能会牺牲首位排序稳定性。

基于上述分析，本文将反事实扰动定位为可信度验证模块和 Top-5 召回增强模块，而不是最终综合最优方法。具体而言，A+S, \(\lambda=0.9\) 负责生成主排序结果；CF 分数用于对 Top-k 候选行进行补充解释，帮助研究者判断候选行是否真正影响模型漏洞预测概率。

## 5.7 本章小结

本章对“基于语义增强执行路径证据的漏洞行级定位与可解释方法”进行了实验验证。实验基于 SARD 测试集，共包含 2648 个样本，其中正样本 589 个、负样本 2059 个。本文采用 `xfg_stem` 策略从 XFG 文件名中提取行级漏洞标签，所有正样本均成功获得行级标签，负样本不生成漏洞行标签。

消融实验结果表明，Attention-only 方法具备一定定位能力，但 Top-1 Accuracy 和 IFA 指标仍存在明显提升空间；Semantic-only 方法显著优于 Attention-only，说明显式安全语义与真实漏洞行具有较强相关性；A+S, \(\lambda=0.9\) 在 Top-1 Accuracy、Top-3 Accuracy、MRR 和 IFA 等主要指标上取得最佳主排序效果，其中 Top-1 Accuracy 为 0.4041，Top-3 Accuracy 为 0.8353，Top-5 Accuracy 为 0.9474，MRR 为 0.6272，IFA 为 1.3447。

反事实扰动实验表明，CF 模块不适合作为最终主排序方法，但能够用于解释可信度验证，并在 A+S+CF 设置下将 Top-5 Accuracy 提升到 0.9542。因此，本文最终将 A+S, \(\lambda=0.9\) 作为主方法，将 CF 模块作为可信度验证和 Top-5 召回增强模块。
