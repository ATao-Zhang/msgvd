# 论文文档说明

本目录用于保存论文写作过程稿、终稿和审查材料。

## 终稿文件

- 论文终稿路径：`docs/thesis/full_paper_final.md`
- 终稿审查报告路径：`docs/thesis/final_review_report.md`

## 文件使用说明

`full_paper_final.md` 是当前唯一论文终稿文件，后续排版、投稿前修改和内容审查均应以该文件为准。

本目录中的分章节文件、图表文件和中间说明文件仅作为写作过程稿、备份或辅助材料保留，不应覆盖或替代 `full_paper_final.md`。

如需继续修改论文正文，建议先修改 `full_paper_final.md`，再视需要同步更新相关过程稿或说明文件，避免不同版本之间产生内容不一致。
